# Realm SDK for Kotlin
Use the Realm SDK for Kotlin to develop Android or iOS apps
using the Android platform or Kotlin Multiplatform (KMP).

## Get Started with the Kotlin SDK
These docs provide minimal-explanation code examples of how to work with the Kotlin SDK.
Use the SDK's open-source database - Realm - as an object store on the
device.

> ****TIP:**** See the [Quick Start](/quick-start.md) to integrate
> Realm into your Kotlin app and get started.
>

### Install the Kotlin SDK
Choose whether to install the Android or the Kotlin Multiplatform version of the Kotlin SDK.

Import the SDK in your Gradle files to get started.

### Define an Object Schema
Use Kotlin to idiomatically define an object schema.

### Configure & Open a Database
You can configure your database to do things like populate initial
data on load, use an encryption key to secure data, and more.

To begin working with your data, configure and open a database.

### Read and Write Data
You can:
- Create, read, update, and delete objects from the database on the device.
- Construct complex queries to filter data.

### React to Changes
Register a change listener to react to changes and perform logic like updating your UI.
